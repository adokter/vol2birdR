# Installs the 'MistNet' libraries

Installs the 'MistNet' libraries

## Usage

``` r
mistnet_install_libs(version, type, install_path, install_config)
```

## Arguments

- version:

  version to install

- type:

  what type of libraries to be installed

- install_path:

  Where libraries should be installed

- install_config:

  the library config
