# Return 'vol2bird' version

Return version of the 'vol2bird' algorithm

## Usage

``` r
vol2bird_version()
```

## Value

an object of class
[numeric_version](https://rdrr.io/r/base/numeric_version.html)

## Examples

``` r
# check installed 'vol2bird' version:
vol2bird_version()
#> [1] ‘1.3.1.9000’
```
