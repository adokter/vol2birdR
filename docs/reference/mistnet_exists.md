# Checks if the 'LibTorch' and 'MistNet' libraries have been installed or not.

Checks if the 'LibTorch' and 'MistNet' libraries have been installed or
not.

## Usage

``` r
mistnet_exists()
```

## Value

TRUE if both 'LibTorch' and 'MistNet' libraries can be found, otherwise
FALSE
